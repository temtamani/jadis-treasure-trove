# JadisArt Legacy Marketplace

Build a Professional Marketplace Website for "JadisArt"

Create a modern, premium, responsive, and production-quality marketplace website named JadisArt.

Company

JadisArt is a company specializing in selling antique, vintage, collectible, and historical items.

The website must look luxurious, elegant, trustworthy, and easy to use. It should feel similar in quality to modern marketplaces while keeping a classic antique atmosphere.

The company logo will be placed in the header, with the company name JadisArt displayed next to it.
